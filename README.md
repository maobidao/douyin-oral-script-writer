# 带货达人脚本生成器

丢一个产品链接，AI 自动出能直接念的口播逐字稿。

## 你是不是也这样

做短视频带货，最难的不是拍，不是剪，是开口之前坐在那发呆：

- 产品拿到手了，对着镜头不知道第一句说什么
- 写出来的稿子像产品说明书，自己念着都尴尬
- 开头太平滑，观众三秒就划走了
- 卖点堆了一堆，看完不知道你到底想让我干嘛
- 今天写一条，明天写一条，每条都像重新投胎
- 好不容易写完，发现价格写错了被投诉虚假宣传

这个 skill 就是解决这件事的。

## 它做什么

达人把一个抖音商品链接发给 AI，AI 自动完成：

1. **读产品**：打开链接，提取品名、卖点、好评关键词、目标人群
2. **写开头**：给你3个不同方向的开头，你挑一个顺眼的
3. **写逐字稿**：200-280字，45-60秒口播量，大白话，像跟朋友推荐东西
4. **自动避坑**：不写具体价格、不碰违禁词、不编卖点

你拿到手的就是能直接对着镜头念的稿子。

## 怎么用

### 在豆包里用

1. 把这个仓库下载到本地
2. 把 `SKILL.md` 的内容作为系统提示词发给豆包，或者把整个文件夹放到豆包的 skills 目录
3. 直接发产品链接给豆包，它就会自动出脚本

### 直接复制提示词

打开 `SKILL.md`，把里面的工作流程和规则复制出来，粘贴到任何 AI 的对话框开头，然后发产品链接。

### 手动填信息

如果链接打不开（需要登录/在App内），把以下信息发给 AI：

```
产品名：
目标人群：
核心卖点（3个）：
```

AI 同样会按方法论出脚本。价格不用写，脚本里不会出现具体数字。

## 方法论

这套方法提炼自短视频带货实战课程，核心包括：

- **4种开头方向**：痛点唤醒、高光前置、圈人群、好奇提问
- **正文结构**：创造需求 → 钩子 → 核心卖点 → 个人感受 → 促单
- **口语化原则**：像跟朋友推荐，不像念稿子
- **合规红线**：不写具体价格、不碰违禁词、不编卖点
- **时长控制**：45-60秒，200-280字
