## 为什么做这个

做短视频带货，最难的不是拍，不是剪，是**开口之前坐在那发呆**：

- 产品拿到手了，对着镜头不知道第一句说什么
- 写出来的稿子像产品说明书，自己念着都尴尬
- 开头太平，观众三秒就划走
- 卖点堆了一堆，看完不知道你到底想让我干嘛
- 今天写一条，明天写一条，每条都像重新投胎
- 好不容易写完，价格写错了被投诉虚假宣传

这个 skill 就是解决这件事的。

## 它做什么

达人把一个抖音商品链接发给 AI，AI 自动完成：

| 步骤 | 做什么 | 输出 |
|------|--------|------|
| 1 读产品 | 打开链接，提取品名、卖点、好评关键词、目标人群 | 内部分析 |
| 2 写开头 | 给你 3 个不同方向的开头，你挑一个顺眼的 | 3 个开头 |
| 3 写逐字稿 | 200-280 字，45-60 秒口播量，大白话 | 逐字稿 |
| 4 自动避坑 | 不写具体价格、不碰违禁词、不编卖点 | 合规输出 |

---

## 4 种开头方向

每条脚本给 3 个不同方向的开头：

- **痛点唤醒**：你家孩子是不是也这样？
- **高光前置**：我儿子拿到这个就没放下过
- **圈人群**：家里有 6-14 岁孩子的，别再买那种玩具了
- **好奇提问**：你知道为什么宝宝喜欢追着灯按吗？

---

## 正文结构

```
创造需求 → 钩子 → 核心卖点 → 个人感受 → 促单
```

- **创造需求**：先说出用户的痛处或场景
- **钩子**：一句话把人留住
- **核心卖点**：只讲最打动的 2-3 个，不平均用力
- **个人感受**："我自己用着""我家娃"——建立信任
- **促单**：自然引导，不硬推

---

## 合规红线

| 不写 | 原因 | 替代说法 |
|------|------|----------|
| 券后 XX 元 | 活动随时变，被投诉虚假宣传 | "有优惠""很划算" |
| 全网最低 | 违禁词 | 不提价格 |
| 治疗/根治 | 违禁词 | "舒服很多""缓解" |
| 最/第一 | 违禁词 | 不提 |
| 编造卖点 | 链接里没有的不写 | 拿不准就问 |

## 怎么用

### 方式一：在豆包里用

1. 把这个仓库下载到本地
2. 把 `SKILL.md` 的内容作为系统提示词发给豆包
3. 直接发产品链接，自动出脚本

### 方式二：直接复制提示词

打开 `SKILL.md`，把工作流程和规则复制出来，粘贴到任何 AI 的对话框开头，然后发产品链接。

### 方式三：手动填信息

链接打不开时，把这些发给 AI：

```
产品名：
目标人群：
核心卖点（3个）：
```
