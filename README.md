# 柒叔口播脚本生成器

丢一个产品链接，自动生成可直接拍摄的口播逐字稿（3个开头+逐字稿）。

## 这是什么

柒叔整理的一套 AI Agent 技能文件。达人把产品链接发给 AI，AI 自动：

1. 打开链接读取产品信息（品名、卖点、人群、评价）
2. 按短视频带货方法论生成3个不同方向的开头 + 逐字稿
3. 不写具体价格（避免虚假宣传），大白话直接能念

## 怎么用

### 方式一：在豆包里用

1. 把这个仓库下载到本地
2. 把 `SKILL.md` 的内容作为系统提示词发给豆包，或者把整个文件夹放到豆包的 skills 目录
3. 直接发产品链接给豆包，它就会自动出脚本

### 方式二：直接复制提示词

打开 `SKILL.md`，把里面的工作流程和规则复制出来，粘贴到任何 AI 的对话框开头，然后发产品链接。

### 方式三：手动填信息

如果链接打不开（需要登录/在App内），把以下信息发给 AI：

```
产品名：
目标人群：
核心卖点（3个）：
```

AI 同样会按方法论出脚本。价格不用写，脚本里不会出现具体数字。


## 方法论来源

这套方法提炼自短视频带货实战课程，覆盖：

- **选品**：5个数据指标、10+30配比
- **文案**：4种开头方向、正文结构、改对标方法
- **拍摄**：镜头密度、高转化镜头清单
- **发布**：剪辑要点、流量逻辑
- **追爆**：小爆vs大爆、连爆逻辑
- **避坑**：违禁词红线、违规场景处理
